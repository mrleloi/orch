# Decision 021 — Telemetry-Analyst Model Tier: Sonnet

## Problem

Decision 017 specifies "new sonnet-tier subagent" for `telemetry-analyst`.
Substage 6.2 architect (`6.2-feedback-loop-architect.md` §B.1, §R-5) escalated
to **opus** on grounds of "non-mechanical pattern recognition over heterogeneous
markdown" architectural-ambiguity. 6.2.3 implementer landed `model: opus` in the
agent frontmatter. 6.2.6 spec-compliance reviewer flagged this as a Decision-017
deviation requiring supplementary decision file. 6.2.7 verifier independently
adjudicates.

## Adjudication

The 4 deterministic rules encoded in `.claude/agents/telemetry-analyst.md` §
Phase 3 are **threshold comparisons** over a uniformly-formatted markdown
table emitted by `scripts/utilities/rollup-telemetry.ts`:

| Rule | Operation |
|------|-----------|
| RULE-1 | `p99_duration_ms > 60000` AND `model == sonnet` |
| RULE-2 | `count >= 5` AND `success_rate < 0.6` |
| RULE-3 | `count >= 3` AND top failure mode parsed from comma-list == "C" |
| RULE-4 | `component_type == "agent"` AND `p99_tokens_real > 100000` |

The "heterogeneity" claim in architect §R-5 does not hold — the rollup MD is a
single fixed-column table (verified live: 14 rows, identical schema). Pattern
recognition is unnecessary; the work is parse + threshold compare + emit
templated string. Sonnet is fully sufficient for this shape per
`agent-workspace/constitution/model-routing.md` (sonnet = mechanical execution
within bounded rule set).

## Decision

`telemetry-analyst` is **sonnet-tier** per Decision 017 § Decision. The
architect-time §R-5 escalation to opus is rejected on the following grounds:

1. **P2 (Simplicity First)** — opus is reserved for architectural ambiguity;
   threshold comparisons do not qualify.
2. **Decision 017 § Decision** is the canonical record; architect-time
   escalation requires a supplementary decision file (this one) to override —
   and the rationale fails on inspection.
3. **Cost** — opus is ~5× sonnet. Even at low invocation frequency (~6/year at
   phase boundaries), there is no quality benefit to offset the cost.

## Action

`.claude/agents/telemetry-analyst.md` frontmatter `model: opus` should be
changed to `model: sonnet` in substage 6.5 (carryforward fix, NARROW_FIX
scope). The change is a 1-line edit to a single file; no spec changes
required (Decision 017 already says sonnet).

## Charter Reference

- Karpathy P2 (Simplicity First — minimum capability that solves the problem)
- `model-routing.md` § sonnet-tier criteria (mechanical work within bounded
  rule sets)
- Decision 017 § Decision (sonnet specified)

## Reversibility

Trivial. Single frontmatter line. If real-world rollup data later shows the
analyst genuinely needs opus-grade synthesis (e.g., multi-rollup cross-phase
correlation in v2.2+), re-escalate via new decision file.
