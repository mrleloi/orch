## Failed approaches (learned; avoid retry)

- Foreground Agent dispatch → stalls. **Always** `run_in_background: true`.
- Parallel `git clone &` in single bash line → subshells killed when parent returns. Use sequential `&&` or separate `run_in_background: true` Bash calls.
- Bare relative path in hook commands → `$PWD` at hook-fire time is subagent cwd, not project root. Use `${CLAUDE_PROJECT_DIR:-.}`.
