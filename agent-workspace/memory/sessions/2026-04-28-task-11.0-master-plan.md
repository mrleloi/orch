## §3 Alternatives Considered + Rejected

### Alt-A: 4 parallel substages instead of 3 (split 11.1 by review-source)

**Rejected.** Splitting 11.1 by review-source (10.1 / 10.2 / 10.5.2.B /
10.5.2.C → 4 substages) would inflate the orchestrator overhead (4 dispatches
+ 4 reviewer pairs vs 1+1) without measurable wall-clock gain. The 11 fixes
share a common reviewer (sonnet/medium code-quality); bundling amortizes the
review cost. Phase 9 §9.1 precedent confirms bundled batches close cleanly.

### Alt-B: Move CF-DOGFOOD-2 disposition to 11.6 (after SC-39 verdict known)

**Rejected.** CF-DOGFOOD-2 is structurally INDEPENDENT of SC-39 — the dogfood
harness step-9 stub is unrelated to the dispatch-recorder seam. Moving 11.3
to post-11.5 would forfeit the parallelism opportunity (11.3 currently runs
alongside 11.1 + 11.2). Also, Decision 037 authoring (11.5.3) is enough
context-density already; adding a CF-DOGFOOD-2 disposition decision to the
same substage would over-pack 11.5.3.

### Alt-C: Skip 11.4 mid-verify (rely on 11.7 final verify only)

**Rejected.** Phase 10 §10.4 precedent established the mid-verify as a
risk-mitigation checkpoint that catches regressions from the parallel batch
BEFORE the load-bearing 11.5 substage begins. Skipping 11.4 would push the
regression-detection window to 11.7 — by which point a 11.1 hygiene-batch
regression might have polluted the 11.5 measurement signal. Cost is only 30K
(sonnet/low) — well worth the insurance.

### Alt-D: Promote 11.5.1's `sc39-production-pairing-rate.spec.ts` to a
required green-deadline at 11.5.3

**Partially rejected, partially accepted.** The integration test scaffold
lands in 11.5.1 (architect + impl). The **green-deadline** is OPTIONAL — if
the test does not green by 11.5.3 close (e.g., child-process spawn fails on
harness permission cache), defer the green-deadline to v2.7 while keeping
the test in-tree as `.todo` or `.skip`-flagged. This is the "scaffold-only,
greens-in-v2.7" pattern from §4 row 9. Charter-coherent: the test scaffold
itself is the v2.6 deliverable; greening is v2.7's R-3-equivalent deliverable.

### Alt-E: Author Decision 037 in 11.5.2 instead of 11.5.3 (collapse to 9
substages)

**Rejected.** Decision 037 authoring requires R-2 + R-3 evidence on disk.
Authoring it in 11.5.2 alongside the artifact production would create a
single-substage workflow where the same agent (a) measures and (b) decides
based on its own measurement — confirmation-bias risk. Phase 10 §10.5.3
explicitly split artifact production (sonnet/medium) from decision authoring
(opus/medium) for this reason. Phase 11 inherits the split.
