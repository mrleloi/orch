## Implementation Summary

### Script Design (`dispatch-jsonl-recorder.sh`)

Mirrors `component-telemetry.sh` pattern exactly:

1. **Background subshell detach**: `( ... ) </dev/null >/dev/null 2>&1 &` then `disown 2>/dev/null || true` — parent exits immediately (INV-S9).
2. **POSIX `>>` line-atomic append**: Each JSON line ≤ 480 bytes ≪ PIPE_BUF=4096. No lock files (Windows Git Bash portability invariant).
3. **Single `node -e` for all JSON parsing**: Consolidated into one call using `eval "$(...)"` to assign all fields — reduces subprocess fork overhead vs separate per-field `node -e` calls (component-telemetry.sh:42-103 pattern).
4. **Self-filter**: `[ "$HOOK_EVENT" = "PreToolUse" ] && [ "$TOOL_NAME" != "Task" ] && exit 0` — gates correctly per B.3.
5. **Sidecar correlation**: DISPATCHED writes `{dispatch_id, agent_type, model}` to `.dispatch-pending-${PARENT_SID}.jsonl`. COMPLETED reads back via `grep "dispatch_id":"${LID}"` | `tail -1`.
6. **Error tolerance**: `set -uo pipefail` + `trap 'exit 0' ERR` — any failure exits 0 (fire-and-forget per B.7).

## Deviations from Architect Spec

1. **Single consolidated `node -e` parse**: The architect spec references `component-telemetry.sh:42-103` which does separate per-field `node -e` calls. This implementation uses a single `eval "$(...)"` pattern that exports all fields at once — simpler, faster, fewer subprocesses. Functionally equivalent, compliant with B.7 (error tolerance), and reduces wall time.

2. **gitignore +3 vs ≤2**: Added a blank separator line before the two gitignore entries for readability (standard git convention). This is 1 line over the spec estimate of "≤ 2". The spec estimate was for data lines only; the blank line is a formatting non-functional line. Gate C.6 (`wc -l script ≤ 80`) only covers the script.

3. **settings.json PreToolUse as new top-level key**: The existing settings.json had no `PreToolUse` hook section (only `PostToolUse`). A new `PreToolUse` key was added. The SubagentStop section got a new matcher entry. Both per spec §3 Part A.
