## 3. Critical Findings (Blocking)

### CRIT-1: DEFAULT_USER violates DEFAULT_* centralization invariant - gate FAIL

- File:line: packages/core/src/tenancy/scope-resolver.ts:22
- Code: export const DEFAULT_USER = 'default-user';
- Spec ref: enforced by pre-existing packages/core/src/config/defaults.spec.ts
  invariant: no DEFAULT_* declarations outside config/defaults.ts.
  Test notes: Re-exports export { DEFAULT_X } from ... are PERMITTED.
  Only export const DEFAULT_ declarations are violations.
- Impact: pnpm --filter @orch/core test exits 1. Implementer self-report
  claimed typecheck 0 and +17 tests (accurate for tenancy-isolated run)
  but omitted that the full suite gate FAILS.
- Minimal fix: Move DEFAULT_USER = 'default-user' to
  packages/core/src/config/defaults.ts alongside existing DEFAULT_* constants.
  Then in scope-resolver.ts replace declaration with:
    export { DEFAULT_USER } from '../config/defaults.js';
  Change is < 5 LOC total.
