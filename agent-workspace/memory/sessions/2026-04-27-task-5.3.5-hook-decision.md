Required because `DomainEvent` is now part of the union and the state machine switch must be exhaustive. Without this, `transition()` returned `undefined` at runtime causing `emitSessionEvents` to skip with `newState === undefined` check — deny tests would fail. Transient (no state change), valid in Running/Starting.

2. **spec count 13 not 9**: The spec file has 4 additional unit tests for `HookDecisionSchema` and `HookDecisionPayloadSchema` (parse literals, reject unknown, backward compat, strict reject). The 9 named integration cases per §6.4 all pass; total 13 all pass.

3. **Test dedup note for case 6**: Case 6 verifies the `tool.denied` channel is emitted exactly once (I-8 satisfied via HooksService dedup). The SessionManager `writeStdin` suppression is the CLI-level gate: Claude Code CLI's hook fires before the tool executes, so the tool never runs. The daemon's role is to record + log + OTEL span the denial for observability. This is consistent with P3 (surgical) and the architect's note in §6.3.
