## Decisions Made
- D-1.3-A: Zod v4 API — used `ReturnType<typeof ProfileSchema.safeParse>` instead of `z.SafeParseReturnType` which was removed in zod v4.
- D-1.3-B: Jest moduleNameMapper — added `"^(\\.{1,2}/.*)\\.js$": "$1"` to resolve `.js` extensions in ts-jest without changing source imports (NodeNext module resolution requires `.js` in source).
- D-1.3-C: State machine reactivation — `SessionStart` from `Ended` reactivates (matches Agent-Monitor §2 pattern); `SessionStart` from `Failed` throws (hard failure, no reactivation).
- D-1.3-D: `Stopping` is a stable state, not just transient — once `Stop` fires, session stays `Stopping` until `SessionEnd` or the user sends another prompt (which will be expressed as UserPromptSubmit, no state change here).
