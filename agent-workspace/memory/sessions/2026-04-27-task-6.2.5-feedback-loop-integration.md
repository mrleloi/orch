## Citation Linter Regex

Pattern for identifying proposal bullets that require a citation:
```
/^- \*\*/
```
A line matching this pattern is a proposal bullet. It MUST also contain the literal substring:
```
cites rollup row:
```
If it does not, it is a violation. The linter function `lintRecommendationsCitations()` in
`tests/integration/feedback-loop.spec.ts` is the canonical single-source implementation.
