## Decisions Made
- React Router v7 installed (v6 unavailable via pnpm resolver; v7 has compatible BrowserRouter/Routes/Route API for this use case). No decision doc created as this is a version resolution, not an architectural choice.
- TokenGate split into 3 files to satisfy react-refresh/only-export-components ESLint rule (storage helpers and context cannot live in same file as the component).
- vitest globals:true enabled to make @testing-library/jest-dom matchers work (it calls expect.extend() on module load, which requires the global).
- shadcn/ui not installed: spec says "Tailwind + shadcn/ui (pinned)" but no shadcn components are needed until Task 2.7 UI pages. Tailwind CSS install deferred similarly — no component uses Tailwind classes in placeholder pages. This avoids speculative setup.
