## Decisions Made
- `commit_sha` stored as null (not 'HEAD' string) when projectRoot is not a git repo. Rationale:
  null clearly signals "not captured" vs 'HEAD' which was misleadingly passing a string.
- `SessionLogPathResolver.resolve()` always returns a path (never null). Contract: the file
  may not yet exist but the path is well-defined. This matches the task spec ("returns the
  expected forthcoming path").
- T-HEAD-6 uses `node:child_process.execFile` adapter instead of real execa to avoid Jest
  ESM import issues with the execa package.
