## Decisions Made
- Jest 30 does not auto-set NODE_ENV=test in this pnpm monorepo setup; added src/jest.setup.ts
  via jest config `setupFiles` to set it consistently. No new runtime dep needed.
- Used `Symbol.for('@orch/context')` over a plain module-level variable to survive HMR and
  future multi-package scenarios where both packages might load their own copy of context.ts.
- Placeholder entity types (Session, QueueItem, HookEvent) live in store.ts with a TODO(1.3)
  comment rather than separate files, keeping IOrchStore self-contained until Task 1.3.
- `runtime.ts` imports `Readable` from `node:stream` — this is a Node built-in, not a framework
  import, so it is compliant with I-14.
