# Task 5.1.5 Session Log

## What was done

Refined the Mode-A narration-hit grep in `scripts/hooks/autonomous-stop-watchdog.sh`
(lines 60-63 → now 60-68) to require BOTH:

  (a) a narration-verb pattern match (Dispatching / Now running / Will dispatch / etc.)
  (b) absence of `"type":"tool_use"` in the same 8 KiB tail window

Before this change, the watchdog grep fired `narration_hit=suspected` for any turn
containing a narration verb — even when a tool_use block followed in the same turn.
This caused 33 false-positive entries in `.autonomous-api-error-alert.log` across
Phases 2-3 (H-12/H-14/H-15 in the meta-retro).

The verb regex list is preserved verbatim; only the outer conditional gained an inner
guard: `if ! printf '%s' "$LAST_TAIL" | grep -qE '"type":"tool_use"' ; then`.
