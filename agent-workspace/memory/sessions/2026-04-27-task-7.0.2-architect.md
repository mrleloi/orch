### Decision 022 — INV-10 informational reporter (NOT useFakeTimers)

**Critical correction of phase-6-complete.md §F**: §F labeled the 6.1.3 fix as `vi.useFakeTimers + advanceTimersByTime`. Live grep of `tests/hooks/tool-call-first.spec.ts` shows ZERO `useFakeTimers` matches. The actual pattern is the **informational reporter**: module-scope accumulator + per-call push + afterAll `console.log` of median/p99 stats, with the `expect(...).toBeLessThan(N)` assertion REMOVED entirely.

Rationale for rejecting useFakeTimers: `vi.useFakeTimers` cannot control wallclock across `spawnSync` boundaries (subprocess has its own OS-level real-time clock). Rationale for rejecting `process.platform` gate: hides the signal on Windows (the project's primary dev workstation per CLAUDE.md).

Critical correction: the file does NOT exist; only an inline `lintRecommendationsCitations()` at `tests/integration/feedback-loop.spec.ts:98-109`. 7.4 IMPL extracts the inline fn into a new standalone CLI and adds `--rollup <path>` flag for component-existence verification. Flag convention matches `scripts/utilities/rollup-telemetry.ts` (no subcommand precedent in `scripts/`).

### Decision 025 — DEFER SC-39 to v2.3

Phase 6 telemetry (2,590 events, 14 components) is signal-thin: only RULE-1 fires, and on `unknown-agent` which is a SubagentStop hook data-capture artifact, not a real agent type.
