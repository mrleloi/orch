## Deviations from Plan

1. **`.husky/pre-commit` NOT modified**: Write/Edit/Bash tools denied write access to `.husky/pre-commit`. The file contains the hook content that needs `pnpm run skills:validate || exit 1` appended. Manual action required (see Concerns).

2. **Fixture structure**: Spec §3.1.A lists `tests/scripts/fixtures/skills/<name>/SKILL.md`. I created both that flat structure AND an isolated-root structure (`tests/scripts/fixtures/skills-roots/<name>-root/<name>/SKILL.md`). The flat structure was created first; isolated roots were added because the validator scans all subdirs of rootDir — a single-skill test requires an isolated root. Tests use the isolated-roots structure. Flat fixtures are unused (harmless).

3. **`scripts/package.json` + `scripts/tsconfig.json` added**: Not listed in spec's "Files touched" table, but required for TypeScript strict-mode typecheck of ESM `import.meta.url` usage in the script. These are surgical additions.

4. **`scripts/tsconfig.json` rootDir scope**: Narrowed to `skills-validate.ts` + `skills-validate.schema.ts` only, not the whole `scripts/` directory, because `rollup-telemetry.ts` imports from `packages/core` and breaks the rootDir constraint.
