## Decisions Made

Chose `declare -A NAME=()` explicit init over `${!ARR[@]:-}` parameter default because:
(a) fewer total changes — one token per declaration vs guard expressions at every iteration
site; (b) clearer intent — the =() form is the canonical Bash idiom for empty-array init;
(c) no risk of accidentally suppressing legitimate unbound-variable errors at loop sites.
