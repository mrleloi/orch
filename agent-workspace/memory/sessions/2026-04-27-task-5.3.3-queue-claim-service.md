## Atomic SQL (implemented)

```sql
UPDATE "QueueItem"
SET    "claimedBy"      = :workerId,
       "claimExpiresAt" = :expiry
WHERE  "id" = :itemId
  AND  ("claimedBy" IS NULL
        OR "claimExpiresAt" < :now)
```

Note: Used parameterized `:now` instead of `CURRENT_TIMESTAMP` because Prisma stores
DateTime as ISO-8601 with T separator while CURRENT_TIMESTAMP uses space separator,
causing string comparison to break.

## Key Decision

Replaced `CURRENT_TIMESTAMP` in WHERE clause with a parameterized `${now}` Date to
ensure Prisma's ISO-8601 datetime format is used consistently for comparison, avoiding
the ASCII sort bug where 'T' > ' ' causes expired claims to never be swept.
