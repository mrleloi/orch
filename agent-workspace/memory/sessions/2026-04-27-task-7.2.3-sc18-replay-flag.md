## Implementation Summary

### Functions added/modified

1. **`SC18RealWorldReport` interface** — added `dataSource: 'dispatch.jsonl' | 'session-log-mtime'` field.

2. **`buildReport(records, opts?)`** — added optional second argument `{ dataSource?: 'dispatch.jsonl' | 'session-log-mtime' }` defaulting to `'session-log-mtime'`. Passes through to the returned report object. Existing tests pass because the signature is backward compatible (opts is optional).

3. **`renderMarkdown(report)`** — added branch on `report.dataSource === 'dispatch.jsonl'` to emit the SC-33 methodology paragraph; otherwise emits existing methodology verbatim.

4. **`loadTaskFinishRecordsFromDispatchJsonl(dispatchJsonlPath)` (NEW export)** — reads dispatch.jsonl, groups events by `dispatch_id`, pairs DISPATCHED+COMPLETED events, skips orphans with `console.warn`, computes `taskId = ${agent_type}-${parent_session_id.slice(0,8)}-${dispatched.ts_ms}`, sets `substage = '6.1'` (OQR-12 v2.2 simplification), uses `completed.ts_ms` as `finishTs` (SC-33 PASS condition, not filesystem mtime). Returns sorted ascending by `finishTs`.

5. **`parseArgs()`** — extended return type with `useDispatchJsonl: string | null` (default `null`). Added `--use-dispatch-jsonl <value>` branch in the arg loop.

6. **`main()`** — branches on `useDispatchJsonl`: if set, calls `loadTaskFinishRecordsFromDispatchJsonl(resolve(rootDir, useDispatchJsonl))`; otherwise calls original `loadTaskFinishRecords(resolvedSessionsDir)`. Passes `{ dataSource }` to `buildReport`.

7. **Help text** — extended `--help` output with `--use-dispatch-jsonl <path>` option documentation.
