## Decisions Made
- D1: Kept core's `secret-redactor.ts` implementation in place (no re-export from shared). Reason: @orch/core uses Jest with moduleNameMapper shim (`__orch_shared_shim__.ts`) that only re-exports SSE/envelope symbols. Making core re-export from shared would require patching the shim + risk to 702 core tests. Both packages end up with the same implementation. Telegram imports from @orch/shared; core uses its local copy. This is technically DRY-ish duplication but zero test risk.
- D2: `whitelistMiddleware` signature takes `logger` as second param (not in original Part B spec which shows just `allowedIds`). The logger is needed to implement the "logs denial at warn level" test requirement. This is a minimal, justified extension.
- D3: `registerStatusHandler` takes `logger` as fourth param (not in original Part B spec). Required for ctx.reply error logging (H-1 rule). Documented deviation.
