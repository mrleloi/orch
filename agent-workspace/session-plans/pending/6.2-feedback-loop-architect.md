### 6.2.2 — Telemetry Rollup Script (TS)

#### Part A — Goal

Extend the Phase-5.5 SKELETON `scripts/utilities/rollup-telemetry.ts` (128 LOC
of basic group-and-emit) into a phase-aware aggregator that computes per-
component statistics (count, success_rate, p50/p99 duration_ms, p50/p99
tokens_real, top-3 failure_modes from the A..H enum) and emits a markdown
table at `agent-workspace/memory/component-rollup-phase-<N>.md`. Add 5

`groupEvents`, `emitMarkdown`) MAY be renamed/extended but their behavior
must remain a strict superset.

#### Part B — Contract (machine-mechanical)

2. `tests/scripts/rollup-telemetry.spec.ts` — NEW; ~200 LOC; 5 vitest cases.

**No new schema files. No changes to `component-telemetry.schema.ts`. No daemon

**B.1 — CLI surface**

```sh
pnpm tsx scripts/utilities/rollup-telemetry.ts \
  --phase 6 \
  --input agent-workspace/memory/component-telemetry.jsonl \
  --subagent-index agent-workspace/memory/subagent-index.md \
  --output agent-workspace/memory/component-rollup-phase-6.md
```

CLI flags (parse `process.argv.slice(2)`):
- `--phase <N>` (REQUIRED; non-empty string; appears in output H1 title and default `--output` filename)
- `--input <path>` (OPTIONAL; default `agent-workspace/memory/component-telemetry.jsonl`)
- `--subagent-index <path>` (OPTIONAL; default `agent-workspace/memory/subagent-index.md`; if file missing, emit warning to stderr but continue — degraded mode)
- `--output <path>` (OPTIONAL; default `agent-workspace/memory/component-rollup-phase-<N>.md`)

Exit codes:
- `0` on success.
- `1` on missing `--phase` (stderr usage line).
- `1` on `--input` file ENOENT.
- `0` on malformed JSONL lines (skip silently per `parseTelemetryLine` contract — append-only durability).

**B.2 — Aggregation logic per (component_type, component_name)**

For each unique `(component_type, component_name)` group:

| Field | Computation |
|---|---|
| `count` | total events in group |
| `success_rate` | `ok_count / count` rounded to 3 decimals |
| `p50_duration_ms` | sorted `duration_ms`[floor(0.5 × n)] |
| `p99_duration_ms` | sorted `duration_ms`[floor(0.99 × n)] |
| `p50_tokens_real` | sorted `tokens_real ?? 0`[floor(0.5 × n)] |
| `p99_tokens_real` | sorted `tokens_real ?? 0`[floor(0.99 × n)] |
| `top_failure_modes` | top-3 of `failure_mode` (A..H) ranked by frequency, joined `"A:12,B:3,H:1"` (omit `null` mode); empty string if none |

Schema validation: import `ComponentEventSchema` from
`packages/core/src/telemetry/component-telemetry.schema.ts`. Use existing
`parseTelemetryLine` helper (line 31; already returns `null` on parse fail).

**B.3 — Markdown output structure (the analyst's input)**

**B.3 — Outlier-detection rules (deterministic; cited by analyst, not invented)**

| Rule | Trigger | Section |

| RULE-4 | `p99_tokens_real > 100000` for an agent component | Model Bumps (over-budget; consider opus or session split) |

function lintRecommendationsCitations(recsMd: string): { violations: string[] } {
  const violations: string[] = [];
  const lines = recsMd.split('\n');
  let currentSection = '';
  for (const line of lines) {

    if (line.match(/^- \*\*/) && !line.includes('cites rollup row:')) {
