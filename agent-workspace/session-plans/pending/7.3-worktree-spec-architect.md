### OQR-4 — execa vs spawnSync in test layer

**Decision: Use `spawnSync('git', [...])` from `node:child_process` — NOT execa.**

The brief mandates `execa('git', [...])` for I-3 compliance. However, I-3's actual
requirement is: "no shell-string subprocess; use array args." Every one of the 18 existing
vitest spec files under `tests/` uses `spawnSync(command, args_array)` from
`node:child_process`, never execa. The `tests/` layer has no package.json; execa is a
declared dependency of `packages/core` (v5, hoisted into pnpm store), not of the
root workspace. Importing execa from a test file that has no explicit dependency declaration
creates a fragile implicit dependency on hoisting behavior.

`spawnSync('git', [array_of_args], { encoding: 'utf8' })` satisfies I-3 equally:
- No shell interpolation (no `{ shell: true }`)
- Arguments are array, not string-concatenated command
- No `child_process.exec(string)`

The implementer SHALL use `spawnSync` with explicit array args, NO `{ shell: true }`, and
document this choice in the spec file's top comment citing this architect decision (OQR-4).

## §5 Spec Signature Design

### `tests/integration/worktree-isolation.spec.ts`

**Target LOC**: ≤80. No imports from `packages/core/` (I-13: integration tests are self-contained).

```typescript
/**
 * worktree-isolation.spec.ts
 *
 * Permanent integration spec: promotes the 6.3.8b verifier's P6 probe
 * (bidirectional sentinel-file check) to a CI-gated test.
 *
 * Architect decision OQR-4: uses spawnSync('git', [array]) — the established
 * pattern for all tests/ vitest specs. Equally I-3 compliant as execa:
 * no shell interpolation, explicit array args, no { shell: true }.
 *
 * Platform-skip: hasGitOnPath() — skips on hosts without git in PATH.
 * I-6: no git commit. All worktrees and tmpdirs are cleaned in afterEach.
 *
 * Spec: agent-workspace/session-plans/pending/7.3-worktree-spec-architect.md
 * SC: SC-34
 */

import { describe, it, afterEach, expect } from 'vitest';
import { mkdtempSync, writeFileSync, existsSync, rmSync } from 'node:fs';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { spawnSync } from 'node:child_process';

// --- helpers -----------------------------------------------------------------

function hasGitOnPath(): boolean { /* spawnSync('git', ['--version']) */ }

/** Init a bare git repo (with initial commit) in a tmpdir, return repo path. */
function initRepo(baseDir: string): string { /* git init + config + commit --allow-empty */ }

/** Add a worktree at <repoDir>/<name>. Returns absolute worktree path. */
function addWorktree(repoDir: string, name: string): string { /* git worktree add -b <name> <path> HEAD */ }

/** Remove all worktrees and prune (best-effort, reject:false). */
function pruneWorktrees(repoDir: string): void { /* git worktree prune */ }

// --- suite -------------------------------------------------------------------

describe('worktree isolation', () => {
  const tmpdirs: string[] = [];

  afterEach(() => {
    for (const d of tmpdirs) {
      // git worktree prune then rmSync
    }
    tmpdirs.length = 0;
  });

  it.skipIf(!hasGitOnPath())(
    'Case 1: file written in worktree-A is absent in worktree-B (forward isolation)',
    () => { /* write __SENTINEL_FROM_A.txt; assert absent in wtb */ }
  );

  it.skipIf(!hasGitOnPath())(
    'Case 2: file written in worktree-B is absent in worktree-A (reverse isolation)',
    () => { /* write __SENTINEL_FROM_B.txt; assert absent in wta */ }
  );

  it.skipIf(!hasGitOnPath())(
    'Case 3: prune removes both worktrees, no sentinel files leak to tmpdirs',
    () => { /* both prune; assert worktree dirs gone from tmpdir */ }
  );
});
```

**Key implementation notes for implementer**:

1. `hasGitOnPath()`: `spawnSync('git', ['--version'], { stdio: 'ignore' }).status === 0`.
   Cache result. Use for `it.skipIf`.

2. `initRepo(baseDir)`: create tmpdir via `mkdtempSync(join(tmpdir(), 'orch-wt-test-'))`,
   push into `tmpdirs`, then:
   - `spawnSync('git', ['init', '-q'], { cwd: dir })`
   - `spawnSync('git', ['config', 'user.email', 't@t.t'], { cwd: dir })`
   - `spawnSync('git', ['config', 'user.name', 't'], { cwd: dir })`
   - `spawnSync('git', ['commit', '--allow-empty', '-q', '-m', 'init'], { cwd: dir })`
   Return `dir`.

3. `addWorktree(repoDir, name)`: worktreePath = `join(repoDir, name)`.
   - `spawnSync('git', ['worktree', 'add', '-q', '-b', name, worktreePath, 'HEAD'], { cwd: repoDir })`
   Return `worktreePath`.

4. `pruneWorktrees(repoDir)`: `spawnSync('git', ['worktree', 'prune'], { cwd: repoDir })`.

5. `afterEach`: for each dir in `tmpdirs`: first `pruneWorktrees(dir)` (best-effort),
   then `rmSync(dir, { recursive: true, force: true })`. This ensures no worktree dirs
   or tmpdir contents leak between tests.

6. Case 1: `initRepo` → `addWorktree('wta')` + `addWorktree('wtb')` → `writeFileSync(join(wta, '__SENTINEL_FROM_A.txt'), 'leak-payload')` → `expect(existsSync(join(wtb, '__SENTINEL_FROM_A.txt'))).toBe(false)`.

7. Case 2: same repo setup → `writeFileSync(join(wtb, '__SENTINEL_FROM_B.txt'), 'leak-from-b')` → `expect(existsSync(join(wta, '__SENTINEL_FROM_B.txt'))).toBe(false)`.

8. Case 3: `initRepo` → `addWorktree('wta')` + `addWorktree('wtb')` → `pruneWorktrees(repoDir)` → `rmSync` both → `expect(existsSync(wta)).toBe(false)` + `expect(existsSync(wtb)).toBe(false)`. Verifies tmpdirs are fully cleaned with no leaked sentinel state.

9. NO `{ shell: true }` anywhere. All git args are string arrays. This is I-3 compliance
   at the test layer.

10. NO `git commit` anywhere in the spec. I-6 compliant: `git commit --allow-empty` in
    `initRepo` creates a commit only in the isolated tmpdir repo, which is entirely deleted
    in `afterEach`. The live project repo (`C:\htdocs\orch-starter`) is never touched.
