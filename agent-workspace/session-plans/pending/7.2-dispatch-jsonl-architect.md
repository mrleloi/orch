If verifier P1 fails → STOP-2 → write Decision 026 to add session-scoped sidecar correlation file. ~10 LOC remediation.

### Risk 2 — Hook stdin payload schema mismatch (LOW)

Actual Claude Code PreToolUse stdin shape may differ from assumed `{tool_name, tool_input.subagent_type, session_id, tool_use_id}`. PreToolUse may not pass `tool_input` if the tool hasn't started yet.

### Risk 3 — `.claude/settings.json` matcher syntax (LOW-MEDIUM)

Matcher `"Task"` may be regex-treated (matching anywhere) or require anchors `"^Task$"`.

**Mitigation**: Verifier P1 catches over-firing (DISPATCHED events for non-Task tools would be obvious in dispatch.jsonl). Fix is 2-character edit.

### Risk 4 — Concurrent-write atomicity on Windows Git Bash (LOW)

OQR-7 cites POSIX `>>` line-atomicity precedent but Windows file system semantics may differ. `component-telemetry.sh:312-343` has been running on Windows since Phase 5 without observed corruption, but a 3-concurrent stress test (verifier P6) hasn't been run for this hook.

**Mitigation**: Verifier P6 IS the stress test. If P6 fails → STOP-3 → write Decision 026 to add `mkdir`-based mutex (portable). ~15 LOC + 1 retest.

**Mitigation**: 2nd arg OPTIONAL with default `'session-log-mtime'`; existing tests compile and run unchanged. Verifier P4 checks byte-identical output (modulo `Generated …`).
