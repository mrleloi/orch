#### B.3.1 Part B contract — `EventRateCounter` (new file)

**Public API**:
```typescript
/**
 * Sliding-window event-rate counter.
 * Counts events received in the last `windowMs` milliseconds.
 * Default window: 60_000 ms (1 minute).
 *
 * Decision-binding: this counter is the SC-28 real-measurement seam.
 * Replaces the Phase 7 mtime-proxy measurement.
 *
 * Domain-pure: ZERO @nestjs/* imports. No I/O. Pure in-memory data structure.
 * Thread-safety: single-process Node.js event loop assumption (no atomics).
 */
export interface EventRateCounterOptions {
  /** Sliding window size in milliseconds. Default 60_000. */
  windowMs?: number;
  /** Clock injection seam for testing. Default Date.now. */
  now?: () => number;
}

export class EventRateCounter {
  constructor(opts?: EventRateCounterOptions);

  /** Record an event observed at `now()` time. O(1) amortized. */
  record(): void;

  /** Number of events recorded in the last windowMs. Evicts stale records. */
  count(): number;

  /** Events-per-second derived from count() / (windowMs / 1000). */
  rate(): number;

  /** Reset all state. Used in tests. */
  reset(): void;
}
```

**Implementation note (for implementer, not architect-binding)**: simplest correct impl is a `number[]` of timestamps; `record()` pushes `now()`; `count()` evicts entries older than `now() - windowMs` from the head, returns length. Eviction lazy at read-time keeps `record()` O(1).

#### B.3.2 Part B contract — sync-seam.ts integration

**Edit point**: inside `class TelemetrySyncSeam` (lines 152-205), add a private field + accessor:

```typescript
// New private field, initialized in constructor
private readonly eventRate: EventRateCounter;

// In constructor (after line 173, after sink resolution)
this.eventRate = new EventRateCounter();

// In emit() (line 184), at the very top BEFORE the `if (!this.enabled) return` guard:
this.eventRate.record();

// New public accessor (after isEnabled() at line 203)
/** SC-28 real event-rate. Counts ALL events seen by emit(), not just forwarded ones. */
getEventRate(): { count: number; ratePerSec: number } {
  return { count: this.eventRate.count(), ratePerSec: this.eventRate.rate() };
}
```

**Design rationale (architect, opus/medium D2)**:
- **Why count BEFORE the disabled-guard**: SC-28 measures observed event volume regardless of whether sync is enabled. The "rate at which the daemon produces events" is independent of "rate at which we forward upstream." This matches Decision 031 §"Default OFF / failures non-blocking" — observation is local and free.
- **Why a separate file (not inlined)**: the counter has its own test surface; keeping `sync-seam.ts` focused on the sink contract preserves the single-purpose seam (Karpathy P2/P3). Also: a community sink (e.g., a Prometheus exporter) may want to import `EventRateCounter` directly without depending on the full seam.
- **Why no OTEL emit shape change**: SC-28 is a *consumer-side* metric, not a wire-format addition. Decision 031 §"Wire format" is unaffected.
- **Why injection seam for `now`**: deterministic tests (the spec MUST NOT use `setTimeout` / `await sleep`). Inject a controlled clock.
- **Constraint (architect-binding)**: implementer MUST NOT add any new env-var, must NOT change `TelemetrySyncOptions`, must NOT change the `TelemetrySink` interface. The counter is observational, internal to the seam.
