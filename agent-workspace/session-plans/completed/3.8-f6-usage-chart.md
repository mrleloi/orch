The hand-rolled chart in `UsageChart.tsx` is already complete with grid lines, two cumulative-token paths, axis labels, legend, and a separate `CostSummaryCard`. Do not introduce a chart library.

### D2. Trace-URL backend formatting

Already implemented per plan: `${url}/trace/${traceId}` with branching on `traceBackend ∈ {otlp, langfuse, none}`. The existing implementation also adds a `data-trace-backend` attribute on the anchor for testability. **Note**: Task 3.9's plan calls for a backend toggle env var — the value already exists in `env.schema.ts` (default `'otlp'`) but the **exporter selection** based on it is 3.9's actual job. If Langfuse changes path layout, 3.9 patches the Web UI branch.

### D3. ContextBudgetService coupling

`ApiController` now depends on `ContextBudgetService`. This crosses a feature-module boundary (api → context-budget). Architecture rule §Cross-module communication says "via events or explicit services". The injection is via constructor with `ContextBudgetModule` imported in `ApiModule` — that is "explicit service" (not a back-channel). Acceptable. **Do not** change to event-bus indirection: that would make a synchronous read-only query async-and-stale, violating Karpathy P2.

### D4. Env-var contract (I-10 boundary)

`ORCH_TRACE_BACKEND_UI_URL` is validated at startup via `validateEnv()` (I-10). The endpoint reads `process.env` at request time rather than from the validated `EnvConfig` cache. **Minor lint**: this works but is a Karpathy P3-style drift from the canonical pattern. **Not a blocker** for this session — note in close-out as Phase 3 polish backlog. If the dev has spare budget, they may inject `ConfigService` and read the validated value, but only if the change is < 5 LOC and tested.

### D5. MODEL_PRICING table maintenance

`MODEL_PRICING` is a static table covering 3 primary models. Anything else returns cost = 0. **Operational risk**: if a session uses a model not in the table, the cost summary silently undercounts. Mitigation: when calculateCostUsd hits an unknown model, log once at warn level (not implemented per #19 scope; flag in close-out as a small Phase 3 polish item, NOT as a 3.8 blocker). I-14 considers cost=0 honest signal not silent bug.
